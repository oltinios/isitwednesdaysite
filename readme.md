# isitwednesday.site - Full Stack App

A full-stack MERN application where users can type messages and store them in MongoDB through a Node/Express backend. The frontend is built with React and features a themed UI with video and real-time input handling.

## 🌐 Live Website

Visit the live version here:  
https://www.isitwednesday.site

> This is the deployed frontend hosted on Appwrite.

## 🧪 Backend (Learning / Development Only)

This repo also contains an Express + MongoDB backend used for learning purposes.

- Node.js + Express API
- MongoDB integration
- Not required for the live frontend deployment

---

## Features

- React frontend with interactive UI
- Express backend API
- MongoDB message storage
- POST API to save user input
- Environment variable support for secure config

---

## Tech Stack

- React
- Node.js
- Express
- MongoDB + Mongoose
- dotenv

### Setup Instructions

1. Clone repo
   git clone <your-repo-url>

2. Install backend dependencies
   npm install

3. Create .env file
   MONGO_URI=your_mongodb_connection_string

4. Start backend server
   node server.js

5. Start frontend
   npm run dev
